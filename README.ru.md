# Discorder-Proxy-Addon

Модуль для Windows x64, который направляет сетевой трафик Discord, включая голосовые и видеозвонки, через локальный SOCKS5-прокси. Подойдёт любой VPN-клиент или прокси-программа, если она открывает SOCKS5-порт и поддерживает UDP. По умолчанию используется `127.0.0.1:10808`.

Модуль работает внутри процессов Discord и не запускает отдельных фоновых программ или служб. После установки окно установщика можно закрыть. Все настройки модуля хранятся в `discord-proxy.ini` рядом с `Discord.exe` в каталоге `app-*`.

Это сторонняя программа, не связанная с Discord. SOCKS5-прокси нужно запустить отдельно.

## Что понадобится

- Windows x64 и Discord x64.
- Локальный SOCKS5-прокси с поддержкой UDP. Без UDP голосовые/видео функции могут не работать.

## Установка

1. Скачайте ZIP со страницы [Releases](../../releases) и распакуйте его.
2. Если у вашего прокси другой адрес или порт, измените `host` и `port` в `discord-proxy.ini`.
3. Запустите `Discord-Proxy.bat`. Если Discord открыт, скрипт предложит завершить его процессы. Подтвердите закрытие — текущий звонок будет прерван.
4. Выберите установку.
5. Откройте Discord.

В меню можно также удалить модуль, указать расположение Discord, открыть файл настроек или удалить логи. Если после обновления Discord установился в новый каталог `app-*`, запустите установку ещё раз.

## Обновление

Скачайте новый релиз, распакуйте его в отдельную папку и запустите `Discord-Proxy.bat`. Выберите «Установить / обновить». Адрес прокси, порт и остальные настройки сохранятся. Если в новой версии появились параметры, которых нет в вашем INI, установщик добавит их со стандартными значениями.

Более старая версия поверх новой не устанавливается; если обновление завершится ошибкой, установщик вернёт прежние DLL и INI.

## Настройки и логи

В `discord-proxy.ini` можно изменить адрес прокси (`host`, `port`), включить или отключить TCP и UDP, а также настроить проксирование Chromium.

Установщик также сохраняет список папок Discord в `%LOCALAPPDATA%\DiscordProcessProxy\installations.json`. Настроек прокси в этом файле нет.

Если в папке Discord ещё нет `discord-proxy.ini`, установщик создаёт его из файла рядом с собой. Существующие значения сохраняются: изменение INI рядом с установщиком не заменяет настройки уже установленного модуля. После установки редактируйте файл в папке Discord — пункт 4 меню открывает именно его. Затем перезапустите Discord.

Для прокси с авторизацией заполните `username` и `password` в секции `[proxy]`:

```ini
[proxy]
username=
password=
```

По умолчанию оба поля пустые — подключение без авторизации. Если она нужна, укажите и логин, и пароль, затем перезапустите Discord. Длина каждого значения — от 1 до 255 байт в UTF-8. Эти настройки сохраняются при обновлении.

С логином и паролем авторизацию для TCP и UDP выполняет DLL. Параметр `chromium_proxy` в этом режиме не применяется, а имена серверов разрешаются через системный DNS.

Запись логов выключена (`log=0`). Если включить её (`log=1`), программа будет вести общий файл `%LOCALAPPDATA%\DiscordProcessProxy\discord-proxy.log` размером не более 2 МиБ. Содержимое сообщений в лог не попадает.

## Ручная сборка

Для сборки нужны Visual Studio Build Tools с компонентом **Desktop development with C++** и Python 3. Запустите `release.cmd` из корня проекта: он соберёт DLL и создаст готовый ZIP с номером версии, например `Discorder-Proxy-Addon-v1.1.1.zip`. Этот ZIP нужно прикреплять к релизу GitHub. В папке `Discorder-Proxy-Addon` будет распакованный пакет с установщиком и DLL.

Отдельно собрать DLL и упаковать её можно командами `native-dll/build.cmd`, затем `python native-dll/package.py`.

Перед выпуском новой версии измените номер в `[addon] version` файла `native-dll/discord-proxy.ini` и поля версии в `native-dll/src/version.rc`, затем пересоберите DLL. Номер тега должен совпадать с версией пакета, например `v1.1.1`.

В GitHub Actions настроена сборка для Windows. При публикации тега вида `v*` workflow прикладывает ZIP к предварительному релизу.

Исходный код и сборочные скрипты находятся в [native-dll](native-dll/). [Лицензия MinHook](native-dll/vendor/minhook/LICENSE.txt) включена в исходники и релизный пакет.
